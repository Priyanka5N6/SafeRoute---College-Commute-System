# SafeRoute - College Commute System (Flutter)

## Run it
1. Install Flutter (https://docs.flutter.dev/get-started/install) and run `flutter doctor`.
2. In a terminal:
   ```
   flutter create saferoute
   ```
3. Delete the generated `lib/` folder and `pubspec.yaml`, then copy this project's `lib/` folder and `pubspec.yaml` into the new `saferoute` folder.
4. Run:
   ```
   cd saferoute
   flutter pub get
   flutter run
   ```
